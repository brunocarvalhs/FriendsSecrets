## 🛠️ Tipo de Alteração
Marque as opções relevantes:
- [ ] 🐞 **Bug Fix** (correção de algo que não funcionava)
- [ ] ✨ **Nova Funcionalidade** (adição de algo novo)
- [ ] ⚡ **Melhoria/Refatoração** (limpeza de código ou melhoria de performance)
- [ ] 💥 **Breaking Change** (alteração que quebra compatibilidade ou exige mudanças em outros módulos)
- [ ] 📚 **Documentação** (mudança apenas em arquivos de docs)
