# Friends Secrets

![Build Status](https://img.shields.io/badge/build-passing-brightgreen)
![Platform](https://img.shields.io/badge/platform-Android-standard)
![Kotlin](https://img.shields.io/badge/kotlin-2.x-purple)
![License](https://img.shields.io/badge/license-MIT-blue)

**Friends Secrets** is a modern, privacy-focused Android application designed to facilitate anonymous social interactions and organize "Secret Santa" (Amigo Secreto) events globally. Built with cutting-edge technologies like Jetpack Compose and Generative AI, it ensures a secure and delightful experience for users worldwide.

## 🚀 Key Features

- **Privacy-First Design:** Locally processed contacts and biometric security.
- **AI Gift Assistant:** Hyper-personalized gift suggestions powered by Google Gemini.
- **Global Compliance:** Fully compliant with GDPR, LGPD, and CCPA standards (2026 Edition).
- **Secure Group Draws:** Randomized, encrypted Secret Santa draws with customizable constraints.
- **Adaptive UI:** Native support for Material You (Material 3) with full accessibility (WCAG 2.2).

## 🛠 Tech Stack

- **Language:** Kotlin 2.x
- **UI Framework:** Jetpack Compose (Adaptive Design)
- **Architecture:** Clean Architecture + Modular MVVM
- **Database/Cloud:** Firebase (Auth, Firestore, Remote Config)
- **AI Integration:** Google Generative AI SDK
- **Security:** Android Biometric API + Keystore System
