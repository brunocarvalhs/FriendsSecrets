# Architecture Decision Records (ADRs)

This directory contains the history of architectural decisions made for the Friends Secrets project. We follow the ADR pattern to ensure that the "why" behind our technical choices is preserved for future maintainers (both humans and AI agents).

## What is an ADR?
An Architecture Decision Record (ADR) is a short text file that describes a specific architectural decision, its context, and its consequences.
- **Status:** Proposed, Accepted, Superceded, or Deprecated.
- **Context:** What is the problem or requirement?
- **Decision:** What are we doing about it?
- **Consequences:** What is the trade-off?
